# 🤖 Mangystau Job Bridge - Telegram Bot

Telegram бот для работодателей Актау. Быстрый MVP для хакатона.

## 🚀 Быстрый старт

```bash
cd mjb-bot
npm install
npm start
```

## 📋 Функции

- **AI Парсинг вакансий** - опишите вакансию текстом, бот автоматически структурирует
- **Быстрая публикация** - вакансия появляется на сайте за 3 секунды
- **Моковые данные** - для демонстрации жюри (без реального API)

## 💬 Примеры использования

### Пример 1: Простая вакансия
```
Нужен официант в 15 мкр, зп 200к
```
**Результат:**
- Должность: Официант
- Микрорайон: 15 мкр
- Зарплата: 200 000 тг

### Пример 2: Срочная вакансия
```
Срочно нужен бариста в 7 мкр, опыт от 1 года
```
**Результат:**
- Должность: Бариста
- Микрорайон: 7 мкр
- Статус: 🔥 СРОЧНО

### Пример 3: Сложная вакансия
```
Ищу SMM-щика на удаленку, инстаграм для салона красоты, 200к
```
**Результат:**
- Должность: SMM
- Зарплата: 200 000 тг

## 🎯 Как запустить для демонстрации

1. Откройте терминал в папке `mjb-bot`
2. Запустите: `npm start`
3. Откройте Telegram и найдите бота @mjb_job_bot
4. Нажмите /start
5. Отправьте текст вакансии, например:
   - "Срочно нужен официант в 15 мкр, зп 200000"
6. Смотрите как бот обрабатывает и показывает результат!

## 🔧 Технические детали

- **Библиотека:** Telegraf 4.x
- **Node.js:** версия 18+
- **Токен:** BOT_TOKEN из .env

## 📱 Команды бота

- `/start` - Начать работу
- `/help` - Помощь
- `➕ Добавить вакансию` - Новая вакансия
- `📋 Мои вакансии` - Список вакансий
