## 1. Введение и Цели Проекта

### 1.1 Название Проекта
**Mangystau Job Bridge (MJB)** — Цифровая платформа для трудоустройства молодежи и малого бизнеса Маңғыстау облысы.

### 1.2 Миссия
Создать единую цифровую экосистему, которая быстро соединяет молодых людей Актау (особенно из категории NEET) с местными работодателями — кафе, магазинами, мастерскими — используя AI для умного сопоставления.

### 1.3 Целевые Показатели (KPI)
- **500+** активных вакансий в первый месяц
- **1000+** зарегистрированных соискателей
- **70%** успешных трудоустройств
- **50+** работодателей (малый бизнес)

---

## 2. Анализ Проблем (Problem Statement)

### 2.1 Боли Рыночного сегмента

| # | Проблема | Кто страдает | Текущее решение |
|---|----------|--------------|------------------|
| 1 | Вакансии разбросаны по WhatsApp/Telegram чатам | Работодатели, Соискатели | Ручной поиск, сарафанное радио |
| 2 | Сложная регистрация на job-сайтах | Малый бизнес (кафе, магазины) | Не используют digital-инструменты |
| 3 | Молодежь не видит возможности в своем микрорайоне | Соискатели 16-25 лет | Уезжают в другие города |
| 4 | Нет подтверждения навыков без диплома | Молодежь без высшего образования | Нет инструментов верификации |
| 5 | Низкая мотивация к обучению | NEET-категория | Нет стимулов |

### 2.2 Целевая Аудитория

**Primary:**
- Молодежь 16-25 лет (студенты, выпускники школ, NEET)
- Малый бизнес Актау (кафе, магазины, СТО, салоны красоты, мастерские)

**Secondary:**
- HR-менеджеры среднего бизнеса
- Центры занятости, социальные службы

## 4. Технический Стек

### 4.1 Технологии

| Уровень | Технология | Обоснование |
|---------|------------|-------------|
| **Frontend** | React 18 + Vite | Быстрая разработка, хорошая экосистема |
| **Styling** | Tailwind CSS + shadcn/ui | Премиум дизайн, готовые компоненты |
| **Routing** | TanStack Router | Типизированный роутинг |
| **Backend** | Supabase (Edge Functions) | PostgreSQL, Auth, Realtime, Serverless |
| **Bot** | Aiogram 3.x (Python) | Популярный, асинхронный |
| **AI** | OpenAI API (GPT-4o, Whisper) | Вакансии, резюме, тесты |
| **Maps** | Leaflet + OpenStreetMap | Бесплатная карта Актау |
| **Hosting** | Cloudflare Pages / Vercel | Бесплатный SSL, CDN |

### 4.2 База Данных (PostgreSQL)

```sql
-- Основные таблицы

-- Пользователи (соискатели)
profiles (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users,
  full_name TEXT,
  age INT,
  phone TEXT,
  district TEXT,  -- микрорайон
  skills TEXT[],  -- массив навыков
  trust_score INT DEFAULT 0,
  video_url TEXT,
  voice_resume_url TEXT,
  created_at TIMESTAMP
)

-- Работодатели
employers (
  id UUID PRIMARY KEY,
  telegram_id BIGINT UNIQUE,
  company_name TEXT,
  contact_name TEXT,
  phone TEXT,
  address TEXT,
  district TEXT,
  created_at TIMESTAMP
)

-- Вакансии
vacancies (
  id UUID PRIMARY KEY,
  employer_id UUID REFERENCES employers,
  title TEXT,
  description TEXT,
  salary_from INT,
  salary_to INT,
  district TEXT,
  requirements TEXT,
  skills_needed TEXT[],
  is_urgent BOOLEAN DEFAULT false,
  status TEXT DEFAULT 'active',
  created_at TIMESTAMP
)

-- Отклики
applications (
  id UUID PRIMARY KEY,
  vacancy_id UUID REFERENCES vacancies,
  user_id UUID REFERENCES profiles,
  status TEXT DEFAULT 'pending',
  match_score INT,
  created_at TIMESTAMP
)

-- Курсы
courses (
  id UUID PRIMARY KEY,
  title TEXT,
  description TEXT,
  category TEXT,
  video_url TEXT,
  duration_minutes INT,
  created_at TIMESTAMP
)

-- Прогресс пользователя в курсах
course_progress (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES profiles,
  course_id UUID REFERENCES courses,
  completed BOOLEAN DEFAULT false,
  certificate_url TEXT,
  completed_at TIMESTAMP
)

-- AI Тесты
ai_tests (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES profiles,
  test_type TEXT,
  results JSONB,
  recommended_jobs TEXT[],
  created_at TIMESTAMP
)
```

## 5. Детали Реализации Unique Features

### 5.1 Интерактивная Карта Актау

**Цель:** Показать вакансии по микрорайонам визуально

**Реализация:**
- Использовать Leaflet с кастомной картой Актау
- Микрорайоны: 1-17 мкр, 20, 21, 27, 28, 29, 31, 32
- При клике на микрорайон → список вакансий
- Цветовая кодировка: зеленый = много вакансий, красный = срочно

**Файл:** `src/components/AktauMap.tsx` (уже существует)

### 5.2 AI Парсинг Вакансий

**Вход:** "Маған 14-мкр-дан официант керек, айлық 150к, тәжірибе маңызды емес"

**Обработка:**
1. Отправить в OpenAI GPT-4
2. AI извлекает: title, salary, district, requirements
3. Сохранить в БД
4. Отправить подтверждение работодателю

**Edge Function:** `supabase/functions/parse-vacancy/index.ts`

### 5.3 Голосовое Резюме

**Процесс:**
1. Пользователь отправляет голосовое (до 2 мин) в Telegram бот
2. Whisper API → текст
3. GPT-4 → структурированное резюме
4. Генерируется PDF
5. Прикрепляется к профилю

**Edge Function:** `supabase/functions/voice-resume/index.ts`

### 5.4 AI Психологический Тест

**Вопросы (10 штук):**
- Предпочитаемая работа (команда / одиночество)
- Рабочий темп (быстрый / размеренный)
- Общение с людьми (много / мало)
- Обучение (теория / практика)

**Результат:**
- Рекомендуемые профессии
- Сильные стороны
- Советы по развитию

### 5.5 Trust Score (Геймификация)

**Начисление баллов:**
- Профиль заполнен: +10
- Курс пройден: +20
- Отзыв работодателя: +30
- Видео-визитка: +15
- Голосовое резюме: +10

**Уровни:**
- Bronze: 0-50
- Silver: 51-150
- Gold: 151-300
- Platinum: 300+

### 5.6 AI Mock Interview

**Процесс:**
1. Выбрать вакансию
2. Выбрать тип HR (строгий / добрый / нейтральный)
3. AI задает вопросы
4. Записывает ответы
5. Дает фидбек: речь, уверенность, контент

**Edge Function:** `supabase/functions/mock-interview/index.ts`

### 5.7 Panic Button (Срочная вакансия)

**Логика:**
1. Работодатель нажал "Срочно" в боте
2. Вакансия получает `is_urgent = true`
3. На сайте подсвечивается красным
4. Всем подходящим кандидатам в этом микрорайоне → пуш-уведомление

## 6. User Flow (Полный процесс)

### 6.1 Flow Работодателя

```
1. Находит бота в Telegram (@mangystau_job_bot)
2. /start → Кнопка "Зарегистрировать компанию"
3. Вводит: Название, контакты, адрес
4. Кнопка "Добавить вакансию"
5. Пишет: "Нужен админ в 5мкр, 180к"
6. AI парсит → Показывает результат
7. Подтверждает → Вакансия на сайте
8. Получает пуш при отклике
9. Просматривает профили
10. Контактирует через бот
```

### 6.2 Flow Соискателя

```
1. Заходит на сайт mjb.kz
2. Регистрация (телефон / Google)
3. Проходит AI тест (5 минут)
4. Видит рекомендованные профессии
5. Смотрит карту вакансий
6. Фильтрует по микрорайону, зарплате
7. Смотрит вакансию → "Откликнуться"
8. (Опционально) Проходит курс
9. Получает сертификат
10. (Опционально) Записывает видео-визитку
11. Получает уведомление от работодателя
12. Выходит на работу
```
